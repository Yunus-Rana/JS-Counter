# JS Counter

🔗 **[Live Demo](https://yunus-rana.github.io/JS-Counter/)**

A simple counter app built with vanilla HTML, CSS, and JavaScript. Increase, decrease, or reset a number with a clean, minimal UI.

## Tech Stack

- HTML
- CSS
- JavaScript (no frameworks or libraries)

## Features

- Increase and decrease the counter
- Reset back to zero
- Clean, minimal dark-themed UI

## Running Locally

Clone the repo and open `index.html` in your browser — no build steps or dependencies needed.

\`\`\`bash
git clone https://github.com/Yunus-Rana/JS-Counter.git
